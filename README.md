# C-digo-fisquiexp-ufrj-2026
Meu legado para a disciplina de Fisico - Química Experimental
# Tratamento de Dados - [Nome do Experimento de FisQuiExp]

Este repositório contém o script em Python desenvolvido para o processamento de dados, automação de cálculos e geração de gráficos dos experimentos da disciplina de Físico-Química Experimental ([Sigla da Universidade]).

O objetivo deste projeto é deixar um **legado técnico** para as próximas turmas, facilitando a reprodutibilidade dos cálculos e incentivando o uso de ferramentas de programação na análise físico-química.

## 🚀 Funcionalidades dos Scripts
*   Tratamento automatizado dos dados experimentais brutos.
*   Ajuste linear/não-linear de curvas (Regressão pelo método dos mínimos quadrados).
*   Cálculo automático de propagação de incertezas e erros associados.
*   Geração de gráficos padronizados prontos para o relatório (com barras de erro).

## 📂 Estrutura do Repositorio

*   `/dados_exemplo.csv`: Arquivo de entrada com os dados brutos obtidos pelo grupo.
*   `/main.py`: Código-fonte principal com os comentários explicativos.
*   `/graficos_gerados/`: Pasta contendo as imagens geradas pelo script.

## 💻 Como Utilizar

1. Faça o clone ou baixe este repositório.
2. Substitua os valores do arquivo `dados_exemplo.csv` pelos dados coletados pelo seu grupo.
3. Execute o script principal:
```bash
python main.py
```
